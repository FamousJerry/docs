งานคือการให้เช่าหนึ่งครั้ง เริ่มต้นเมื่อใบเสนอราคาได้รับการยอมรับ และจบเมื่ออุปกรณ์ถูกคืน ตรวจสภาพ และออกใบแจ้งหนี้สุดท้าย

## วิธีสร้างงาน

งานไม่ได้สร้างจากต้น — เริ่มจากใบเสนอราคาที่ accepted แล้วเสมอ เมื่อใบเสนอราคา accepted และเซ็นแล้ว:

<Steps>
  <Step title="เปิดใบเสนอราคาที่ accepted">
    จากรายการใบเสนอราคาหรือจากพาเนลรายละเอียดลูกค้า
  </Step>
  <Step title="คลิก 'สร้างงาน'">
    พาเนลยืนยันแสดงวันที่ บรรทัด และการจองอุปกรณ์
  </Step>
  <Step title="ยืนยันวันที่งาน">
    ค่าเริ่มต้นจากใบเสนอราคา ปรับหากวันที่จริงเปลี่ยน
  </Step>
  <Step title="ยืนยัน">
    งานถูกสร้างในขั้นตอน **New** ใบเสนอราคาเปลี่ยนเป็น **Job Created**
  </Step>
</Steps>

งานสืบทอดทุกอย่างจากใบเสนอราคา — บรรทัด ชุดอุปกรณ์ ลูกค้า วันที่ เงินมัดจำ จากจุดนี้ งานเป็นเอกสารทำงาน การเปลี่ยนแปลงในใบเสนอราคาไม่ส่งผลต่องาน

## รูปแบบเลขที่งาน

งานมีเลขที่อัตโนมัติ: `JOB-YYYY-NNNN`

- `JOB` — คำนำหน้างาน (กำหนดได้ใน **Settings → Business Settings**)
- `YYYY` — ปีที่สร้างงาน
- `NNNN` — ลำดับต่อปี เติม 0 ครบ 4 หลัก

เลขที่งานเป็นอิสระจากเลขที่ใบเสนอราคา ใบเสนอราคา `QT-2569-0042` อาจกลายเป็นงาน `JOB-2569-0058` หากมีงานอื่นถูกสร้างระหว่างกลาง

## หน้ารายการงาน

โมดูลงานเริ่มต้นด้วย **มุมมองบอร์ด** หนึ่งคอลัมน์ต่อขั้นตอน คุณสลับเป็น **มุมมองรายการ** ได้

## สถานะ (ขั้นตอนของงาน)

งานเคลื่อนผ่าน 7 ขั้นตอน:

| ขั้นตอน | สิ่งที่เกิดขึ้น |
| --- | --- |
| **New** | งานมีอยู่แต่ยังไม่เลือกอุปกรณ์ |
| **Picking** | ทีมกำลังสแกนอุปกรณ์ในคลัง |
| **Loaded** | โหลดเข้ารถแล้ว พร้อมออกเดินทาง |
| **Delivering** | อุปกรณ์อยู่ระหว่างจัดส่ง |
| **On Site** | อุปกรณ์อยู่ที่สถานที่ของลูกค้า |
| **Returning** | อุปกรณ์กำลังกลับ |
| **Closed** | คืนแล้ว ตรวจแล้ว ออกใบแจ้งหนี้แล้ว |

## การอัปเดตเรียลไทม์สำหรับทีม

การเปลี่ยนสถานะของงานทุกครั้งจะถ่ายทอดแบบเรียลไทม์ไปยัง:

- พนักงานทุกคนที่เปิดงานอยู่
- มุมมองบอร์ดรายการงาน
- วิดเจ็ต "Active Jobs" บนแดชบอร์ด
- พอร์ทัลของลูกค้า (ลูกค้าเห็นเวอร์ชันที่เป็นมิตรกว่า)

## การยกเลิกงาน

หากต้องยกเลิกงาน (ลูกค้าถอนตัว วันที่เลื่อนไม่ได้):

1. เปิดงาน
2. คลิกเมนู **•••** เลือก **Cancel Job**
3. เลือกว่าจะปล่อยการจองอุปกรณ์หรือไม่
4. ยืนยัน

งานเปลี่ยนเป็น **Cancelled** อุปกรณ์ปล่อยหากคุณติ๊กตัวเลือก ใบเสนอราคาที่เกี่ยวข้องไม่มีผลกระทบ

งานทุกงานใน JingjaiOps ผ่าน 7 ขั้นตอนตั้งแต่สร้างจนปิด ขั้นตอนสะท้อนสถานะทางกายภาพของอุปกรณ์ ไม่ใช่แค่เอกสาร

## 7 ขั้นตอน

<Steps>
  <Step title="New (ใหม่)">
    งานสร้างจากใบเสนอราคาที่ accepted แล้ว อุปกรณ์ถูกจองแต่ยังไม่ได้ดึง
  </Step>
  <Step title="Picking (กำลังเลือก)">
    ทีมกำลังเลือกอุปกรณ์ในคลังและสแกนออก แท็บ Pick & Scan ใช้งานได้
  </Step>
  <Step title="Loaded (โหลดแล้ว)">
    อุปกรณ์ทั้งหมดสแกนและโหลดเข้ารถจัดส่ง พิมพ์ Manifest ได้
  </Step>
  <Step title="Delivering (กำลังจัดส่ง)">
    รถออกจากคลัง อุปกรณ์อยู่ระหว่างทางไปยังสถานที่ของลูกค้า
  </Step>
  <Step title="On Site (อยู่หน้างาน)">
    อุปกรณ์ถึงปลายทาง ลูกค้าเซ็นรับและนาฬิกาเช่าเริ่มเดิน
  </Step>
  <Step title="Returning (กำลังคืน)">
    อุปกรณ์กำลังถูกเก็บและนำกลับสู่คลัง
  </Step>
  <Step title="Closed (ปิดงาน)">
    คืนแล้ว ตรวจสภาพ บันทึกสภาพ สร้างรายงาน AI ออกใบแจ้งหนี้ จบงาน
  </Step>
</Steps>

## การเลื่อนขั้นตอน

แต่ละขั้นตอนมีปุ่มหลักที่ด้านบนของหน้ารายละเอียดงาน ป้ายเปลี่ยนตามขั้นตอนปัจจุบัน:

| ขั้นตอนปัจจุบัน | ปุ่มหลัก | ไปที่ |
| --- | --- | --- |
| New | Start Picking | Picking |
| Picking | Mark Loaded | Loaded (เมื่อสแกนครบ) |
| Loaded | Mark Delivering | Delivering |
| Delivering | Mark On Site | On Site |
| On Site | Mark Returning | Returning |
| Returning | Start Inspection | เปิดแท็บ Return & Inspect |
| (หลังตรวจ) | Close Job | Closed |

## ปุ่ม "Go Back"

ขั้นตอนไม่ได้เดินไปข้างหน้าเสมอ บางครั้งคุณเลื่อนผิด เช่น Mark Loaded ทั้งที่อุปกรณ์ยังขาด

ผู้ดูแลระบบเห็นปุ่ม **Go Back** ที่ด้านบนของหน้ารายละเอียด ย้อนกลับไป 1 ขั้นตอน:

- Loaded → Picking
- Delivering → Loaded
- On Site → Delivering
- Returning → On Site

การกระทำถูกบันทึกใน Audit Trail พร้อมว่าใครคลิกและเมื่อไหร่

## การมองเห็นการเปลี่ยนขั้นตอน

ทุกการเปลี่ยนขั้นตอนเห็นโดย:

- ทีมงานทั้งหมด (เรียลไทม์ ไม่ต้องรีเฟรช)
- ลูกค้าในพอร์ทัล (พร้อมป้ายที่เป็นมิตรกว่า)

### ลูกค้าเห็นขั้นตอนอย่างไร

ในพอร์ทัลลูกค้า ชื่อขั้นตอนภายในแปลเป็นภาษาที่ลูกค้าเข้าใจ:

| ขั้นตอนภายใน | ป้ายในพอร์ทัลลูกค้า |
| --- | --- |
| New | ยืนยันการจองแล้ว |
| Picking | กำลังเตรียมอุปกรณ์ |
| Loaded | พร้อมจัดส่ง |
| Delivering | กำลังจัดส่ง |
| On Site | กำลังเช่า |
| Returning | กำลังเก็บคืน |
| Closed | เสร็จสิ้น |

ลูกค้าจะไม่เห็นการสแกนอุปกรณ์ภายใน การแจ้งเตือนของหาย หรือบันทึกภายในของคุณ ลูกค้าเห็นแถบความคืบหน้าที่ชัดเจนและเรียบง่าย

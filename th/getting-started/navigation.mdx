JingjaiOps ใช้แถบเมนูด้านซ้ายเป็นเมนูหลัก และแถบด้านบนเป็นแถบเครื่องมือทั่วไป เมื่อคุ้นเคยกับการจัดวางแล้ว ทุกหน้าจะรู้สึกคุ้นเคย

## โมดูลในแถบเมนูด้านข้าง

แถบเมนูด้านข้างเป็นวิธีหลักในการเปลี่ยนระหว่างโมดูล แต่ละไอคอนเปิดโมดูลหนึ่ง

| โมดูล | สิ่งที่อยู่ในนั้น |
| --- | --- |
| **แดชบอร์ด** | KPI โดยสรุป งานวันนี้ ใบแจ้งหนี้ค้างชำระ และกิจกรรมล่าสุด |
| **ลูกค้า** | โปรไฟล์ลูกค้า ผู้ติดต่อ คะแนนสุขภาพ และลิงก์พอร์ทัล |
| **ใบเสนอราคา** | ใบเสนอราคา draft, sent, accepted และที่หมดอายุ |
| **งาน** | งานที่กำลังดำเนินการตามขั้นตอน รวมถึงงานที่ปิดและยกเลิก |
| **ใบแจ้งหนี้** | ใบแจ้งหนี้ การชำระเงิน เรียกเก็บแบบรายรอบ และใบเสร็จ |
| **คลังอุปกรณ์** | อุปกรณ์ ชุดอุปกรณ์ หมวดหมู่ และนำเข้า CSV |
| **เงินมัดจำ** | เงินมัดจำที่ถือไว้ คืนแล้ว หรือรอเก็บ |
| **รายงาน** | รายงานมาตรฐาน และเครื่องมือ AI **ถามข้อมูลของคุณ** |
| **ตั้งค่า** | ตั้งค่าธุรกิจ ผู้ใช้งาน การแจ้งเตือน และหมวดหมู่ (ผู้ดูแลระบบเท่านั้น) |

<Tip>
  คลิกปุ่มย่อแถบเมนูด้านล่างเพื่อสลับระหว่างแบบเต็มและแบบไอคอนเท่านั้น ความชอบของคุณจะถูกจดจำต่อแต่ละอุปกรณ์
</Tip>

## ปุ่มสร้างใหม่ (Quick Create)

ปุ่ม **+** สีเหลืองที่มุมขวาบนเปิดเมนูสร้างใหม่จากทุกที่ในแอป

คุณสามารถสร้าง:

- ลูกค้าใหม่
- ใบเสนอราคาใหม่
- งานใหม่ (จากใบเสนอราคา)
- ใบแจ้งหนี้ใหม่
- รายการอุปกรณ์ใหม่
- เงินมัดจำใหม่

แต่ละตัวเลือกจะเปิดฟอร์มแบบ slide-over โดยไม่เสียตำแหน่งหน้าปัจจุบัน

## การค้นหา

กด <kbd>⌘ K</kbd> บน Mac หรือ <kbd>Ctrl K</kbd> บน Windows เพื่อเปิดการค้นหาทั่วระบบจากทุกหน้า

การค้นหาครอบคลุม:

- ลูกค้า (ชื่อ อีเมล โทรศัพท์ เลขประจำตัวผู้เสียภาษี)
- ใบเสนอราคาและใบแจ้งหนี้ (เลขที่ ชื่อลูกค้า)
- งาน (เลขที่งาน ชื่อลูกค้า อุปกรณ์ที่สแกน)
- คลังอุปกรณ์ (Asset ID บาร์โค้ด ชื่อ Serial Number)

ผลลัพธ์ถูกจัดกลุ่มตามประเภท กด <kbd>Enter</kbd> เพื่อเปิดผลลัพธ์อันดับหนึ่ง หรือคลิกผลใดก็ได้เพื่อข้ามไปยังจุดนั้น

## แถบแจ้งเตือนเวอร์ชันใหม่

เมื่อเราออกอัปเดต แถบสีเหลืองจะปรากฏที่ด้านบนของหน้าจอ:

> **มีเวอร์ชันใหม่ของ JingjaiOps พร้อมใช้งาน รีเฟรชเพื่ออัปเดต**

คลิก **รีเฟรช** เพื่อโหลดเวอร์ชันใหม่ ข้อมูลที่ยังไม่ได้บันทึกในฟอร์มที่เปิดอยู่จะคงอยู่ระหว่างการรีเฟรช

## คีย์ลัด

| คีย์ลัด | การกระทำ |
| --- | --- |
| <kbd>⌘ K</kbd> / <kbd>Ctrl K</kbd> | เปิดการค้นหาทั่วระบบ |
| <kbd>⌘ /</kbd> / <kbd>Ctrl /</kbd> | แสดงคีย์ลัดทั้งหมด |
| <kbd>G</kbd> ตามด้วย <kbd>D</kbd> | ไปที่แดชบอร์ด |
| <kbd>G</kbd> ตามด้วย <kbd>C</kbd> | ไปที่ลูกค้า |
| <kbd>G</kbd> ตามด้วย <kbd>Q</kbd> | ไปที่ใบเสนอราคา |
| <kbd>G</kbd> ตามด้วย <kbd>J</kbd> | ไปที่งาน |
| <kbd>G</kbd> ตามด้วย <kbd>I</kbd> | ไปที่ใบแจ้งหนี้ |
| <kbd>N</kbd> | เปิดเมนูสร้างใหม่ |

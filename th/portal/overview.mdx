พอร์ทัลลูกค้า (Client Portal) คือเว็บไซต์ที่ลูกค้าใช้ ลูกค้าทุกคนดูงาน ใบแจ้งหนี้ ใบเสร็จ และเงินมัดจำได้ผ่าน URL เดียวที่ใช้บนมือถือได้ — ไม่ต้องตั้งรหัสผ่าน ไม่ต้องติดตั้งแอป

## พอร์ทัลคืออะไร

พอร์ทัลเป็นหน้าต่างดูข้อมูลที่ทีมของคุณจัดการใน JingjaiOps จาก URL เดียว ลูกค้าสามารถ:

- ดูงานปัจจุบันและที่ผ่านมาพร้อมการอัปเดตขั้นตอนเรียลไทม์
- ดาวน์โหลดทุกใบแจ้งหนี้ ใบเสร็จ เอกสารเงินมัดจำ และใบเสนอราคาที่เซ็นแล้ว
- ชำระใบแจ้งหนี้ค้างชำระผ่าน QR PromptPay
- ยอมรับและเซ็นใบเสนอราคาใหม่
- ดูเงินมัดจำที่ถือไว้และที่คืนแล้ว
- ดูสรุปบัญชีโดยรวม

พอร์ทัลอัปเดตเรียลไทม์ หากคลังของคุณทำเครื่องหมายงานเป็น **Loaded** ลูกค้าเห็นในวินาทีเดียวกัน

## ใครเข้าถึงได้

ใครก็ตามที่มีลิงก์พอร์ทัล แต่ละลูกค้า (หรือใบเสนอราคา หรือใบแจ้งหนี้) มีลิงก์ของตัวเอง ลิงก์เป็น Credential — ไม่ต้องมี Username หรือรหัสผ่าน

ลิงก์มี Scope:

- **ลิงก์ทั่วลูกค้า** — เห็นทุกงาน ใบแจ้งหนี้ เงินมัดจำ และใบเสนอราคาของลูกค้านั้น
- **ลิงก์ใบเสนอราคาเดียว** — เฉพาะใบเสนอราคาเดียว (ใช้ส่งเพื่อเซ็น)
- **ลิงก์ใบแจ้งหนี้เดียว** — เฉพาะใบแจ้งหนี้เดียว (ใช้ส่งคำขอชำระเงิน)

## ไม่ต้องตั้งรหัสผ่าน

JingjaiOps ไม่กำหนดให้ลูกค้าสร้างบัญชี เราเลือกการออกแบบนี้เพราะ:

- **เสียดทานน้อย** — ลูกค้าส่วนใหญ่ยุ่งเกินกว่าจะลงทะเบียน ตั้งรหัสผ่าน และจำ
- **เริ่มต้นเร็ว** — คลิกลิงก์ในอีเมลแล้วเข้าได้เลย
- **เน้นมือถือ** — ไม่มี App Store ไม่ติดตั้ง แค่ URL

ข้อแลกเปลี่ยนคือลิงก์เองมีความสำคัญ หากส่งต่อ ใครก็ตามที่ได้ลิงก์ดูข้อมูลของลูกค้าได้ เราลดความเสี่ยงด้วย:

- **วันหมดอายุของลิงก์** (30 วันสำหรับลิงก์ทั่วลูกค้า)
- **การเพิกถอน Token** (คุณเพิกถอนลิงก์ใดก็ได้ทุกเมื่อ)
- **ไม่มีการชำระเงินจากพอร์ทัล** (PromptPay ต้องให้ลูกค้าสแกนและชำระเอง พอร์ทัลไม่ย้ายเงินเอง)

## ใช้บนมือถือ

พอร์ทัลออกแบบเน้นมือถือ ออกแบบมาใช้บนโทรศัพท์ขณะรอที่ร้านกาแฟหรืออยู่หน้างาน ใช้ได้บน:

- iOS Safari, Chrome
- Android Chrome, Samsung Internet
- เบราว์เซอร์มือถือหรือแท็บเล็ตสมัยใหม่

ประสบการณ์เดสก์ท็อปก็ใช้ได้ดี แต่ลูกค้าส่วนใหญ่เปิดบนโทรศัพท์

## ลูกค้าทำอะไรได้บ้าง

| คำสั่ง | ใช้ได้ |
| --- | --- |
| ดูใบเสนอราคา | ✅ |
| ยอมรับและเซ็นใบเสนอราคา | ✅ |
| ดาวน์โหลด PDF ใบเสนอราคา | ✅ |
| ชำระเงินมัดจำ (ผ่าน PromptPay) | ✅ |
| ดูงานและขั้นตอนปัจจุบัน | ✅ |
| ดูใบแจ้งหนี้ | ✅ |
| ชำระใบแจ้งหนี้ (ผ่าน PromptPay) | ✅ |
| ดาวน์โหลดทุกเอกสาร | ✅ |
| สลับ EN / TH | ✅ |

## ภาษา

พอร์ทัลรองรับภาษาอังกฤษและไทย ครั้งแรกที่ลูกค้าเข้าชม ภาษาตรงกับฟิลด์ **Preferred Language** ในข้อมูลลูกค้า ลูกค้าสลับ EN/TH ด้วยปุ่มที่มุมขวาบนได้ทุกเมื่อ และตัวเลือกอยู่ต่อต่ออุปกรณ์

ใบแจ้งหนี้คือคำขอชำระเงินจากลูกค้า JingjaiOps สร้างใบแจ้งหนี้อัตโนมัติจากงานและติดตามจนถึงการออกใบเสร็จสุดท้าย

## วิธีสร้างใบแจ้งหนี้

ใบแจ้งหนี้ถูกสร้างจากงาน ไม่ใช่จากต้น:

- **เมื่อสร้างงาน** — ใบแจ้งหนี้ฉบับร่างถูกสร้างอัตโนมัติตามยอดใบเสนอราคา อยู่ในสถานะ **Draft** จนกว่าจะส่ง
- **เมื่อปิดงาน** — ฉบับร่างถูกทำให้สมบูรณ์ด้วยการขยาย ค่าความเสียหาย และการปรับ คุณส่งให้ลูกค้า
- **สำหรับงานยาว** — ใบแจ้งหนี้แบบรายรอบจะออกตามตารางที่ตั้ง

## รูปแบบเลขที่ใบแจ้งหนี้

ใบแจ้งหนี้ใช้รูปแบบ `INV-YYYY-NNNN`:

- `INV` — คำนำหน้าใบแจ้งหนี้ (กำหนดได้ใน **Settings → Business Settings**)
- `YYYY` — ปีที่ออกใบแจ้งหนี้
- `NNNN` — ลำดับ เติม 0 ครบ 4 หลัก รีเซ็ตทุกปี

เลขที่ถูกกำหนดเมื่อคลิก **ส่ง** (หรือ **Finalize**) ฉบับร่างไม่มีเลข — แสดงเป็น **Draft #JOB-2569-0042**

## หน้ารายการใบแจ้งหนี้

รายการแสดงทุกใบด้วยคอลัมน์:

| คอลัมน์ | สิ่งที่แสดง |
| --- | --- |
| เลขที่ | `INV-YYYY-NNNN` |
| ลูกค้า | ชื่อลูกค้า |
| วันที่ออก | วันที่ส่งใบแจ้งหนี้ |
| วันครบกำหนด | ค่าเริ่มต้น = วันออก + เงื่อนไขการชำระ |
| ยอดรวม | รวม VAT |
| ชำระแล้ว | จำนวนที่ได้รับจนถึงตอนนี้ |
| ยอดคงเหลือ | ยอดรวมลบยอดที่ชำระแล้ว |
| สถานะ | Draft / Sent / Partial / Paid / Overdue |

## สถานะ

| สถานะ | ความหมาย |
| --- | --- |
| **Draft** | สร้างแล้ว ยังไม่ส่ง ไม่มีเลขที่ |
| **Sent** | ส่งแล้ว รอการชำระ |
| **Partial** | ชำระบางส่วน ยอดคงเหลือยังค้าง |
| **Paid** | ชำระเต็มจำนวน ออกใบเสร็จแล้ว |
| **Overdue** | เลยวันครบกำหนดและยังมียอดคงเหลือ |

การเปลี่ยนสถานะเป็นอัตโนมัติ คุณไม่ต้องเปลี่ยนเอง

## การอัปเดตเรียลไทม์

การเปลี่ยนสถานะใบแจ้งหนี้เห็นเรียลไทม์ทั่ว:

- รายการใบแจ้งหนี้
- โปรไฟล์ลูกค้า (คอลัมน์ค้างชำระ)
- คะแนนสุขภาพลูกค้า
- วิดเจ็ต "Outstanding" บนแดชบอร์ด
- พอร์ทัลลูกค้า — ลูกค้าเห็น "Paid" ทันทีที่คุณบันทึกการชำระ

## คำสั่งทั่วไป

จากหน้ารายละเอียดใบแจ้งหนี้:

| คำสั่ง | ทำอะไร |
| --- | --- |
| ส่งให้ลูกค้า | อีเมล PDF + ลิงก์พอร์ทัลให้ชำระ |
| บันทึกการชำระ | ทำเครื่องหมายว่าใบแจ้งหนี้ชำระทั้งหมดหรือบางส่วน |
| ออกใบกำกับภาษี | สร้างใบกำกับภาษีไทย |
| สร้างใบเสร็จ | ออกใบเสร็จสำหรับการชำระที่ได้รับ |
| ใช้ Credit Note | ลดยอดใบแจ้งหนี้ (คืนสินค้า ปรับยอด) |
| Void | ยกเลิกใบแจ้งหนี้ในสถานะ Draft หรือ Sent (ผู้ดูแลระบบเท่านั้น) |

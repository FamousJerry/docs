ใบเสนอราคาคือข้อเสนอที่มีการระบุราคาให้ลูกค้า เมื่อลูกค้ายอมรับและเซ็นด้วยลายเซ็นดิจิทัล ใบเสนอราคาจะกลายเป็นงานและอุปกรณ์จะถูกจอง

## วงจรชีวิตของใบเสนอราคา

<Steps>
  <Step title="Draft (ฉบับร่าง)">
    คุณสร้างใบเสนอราคาโดยเพิ่มอุปกรณ์จากคลัง ชุดอุปกรณ์ หรือบรรทัดด้วยตนเอง ยังไม่มีใครภายนอกทีมเห็น
  </Step>
  <Step title="Sent (ส่งแล้ว)">
    คุณส่งอีเมลหรือลิงก์พอร์ทัล ลูกค้าสามารถดูใบเสนอราคาได้
  </Step>
  <Step title="Accepted (ยอมรับแล้ว)">
    ลูกค้าเซ็นด้วยลายเซ็นดิจิทัลผ่านพอร์ทัล แนบ PDF ที่เซ็นแล้วและขอเงินมัดจำ (ถ้ามี)
  </Step>
  <Step title="Job Created (สร้างงานแล้ว)">
    คุณแปลงใบเสนอราคาเป็นงานด้วยคลิกเดียว งานสืบทอดบรรทัดและวันที่จากใบเสนอราคา
  </Step>
</Steps>

ใบเสนอราคาอาจเปลี่ยนเป็น **Declined (ปฏิเสธ)** (ลูกค้าไม่รับ) หรือ **Expired (หมดอายุ)** (ไม่ได้ยอมรับก่อนวันหมดอายุ)

## หน้ารายการใบเสนอราคา

รายการแสดงทุกใบเสนอราคาด้วยคอลัมน์เหล่านี้:

| คอลัมน์ | สิ่งที่แสดง |
| --- | --- |
| เลขที่ | เลขที่ใบเสนอราคา รูปแบบ `QT-YYYY-NNNN` |
| ลูกค้า | ชื่อลูกค้า |
| วันที่ | วันที่สร้างใบเสนอราคา |
| หมดอายุ | วันที่หมดอายุหากไม่ยอมรับ |
| ยอดรวม | ยอดสุดท้ายรวม VAT |
| สถานะ | Draft / Sent / Accepted / Job Created / Declined / Expired |

คลิกคอลัมน์ใดก็ได้เพื่อเรียงลำดับ ใช้ตัวกรองสถานะที่ด้านบนเพื่อดูเฉพาะสถานะเดียว

## สถานะโดยละเอียด

| สถานะ | ความหมาย | ขั้นตอนถัดไป |
| --- | --- | --- |
| **Draft** | กำลังสร้าง ลูกค้าไม่เห็น | เพิ่มบรรทัดแล้วส่ง |
| **Sent** | ลูกค้ามีลิงก์แล้ว | รอการยอมรับ ติดตามหากจำเป็น |
| **Accepted** | ลูกค้าเซ็นแล้ว ขอเงินมัดจำ (ถ้ามี) | แปลงเป็นงาน |
| **Job Created** | มีงานสำหรับใบเสนอราคานี้ | ใช้งานนั้น |
| **Declined** | ลูกค้าปฏิเสธ | เก็บถาวรหรือแก้ไขแล้วส่งใหม่ |
| **Expired** | เลยวันหมดอายุโดยไม่ได้ยอมรับ | ออกใบเสนอราคาใหม่หากยังเกี่ยวข้อง |

## การอัปเดตเรียลไทม์

การเปลี่ยนสถานะใบเสนอราคาทุกครั้งจะปรากฏแบบเรียลไทม์ให้ทุกคนในทีม หากลูกค้ายอมรับใบเสนอราคาบนโทรศัพท์ตอน 21:47 หัวหน้าฝ่ายขายของคุณจะเห็นสถานะเปลี่ยนเป็น **Accepted** โดยไม่ต้องรีเฟรช

นี่ใช้ได้กับขั้นตอนเงินมัดจำเช่นกัน — เมื่อชำระเงินมัดจำแล้ว ทั้งใบเสนอราคาและแท็บเงินมัดจำของลูกค้าอัปเดตทันที

## เนื้อหาใน PDF ใบเสนอราคา

PDF ใบเสนอราคาเป็นสองภาษา (EN/TH) และมี:

- ส่วนหัวบริษัทของคุณ (โลโก้ ชื่อ ที่อยู่ เลขประจำตัวผู้เสียภาษี)
- รายละเอียดลูกค้า
- เลขที่ใบเสนอราคา วันที่ออก วันหมดอายุ
- บรรทัดรายการ พร้อมคำอธิบาย จำนวน ระยะเวลา อัตรา ยอดบรรทัด
- รายการเสริม (ทำเครื่องหมายชัดเจน ไม่รวมในผลรวมย่อย)
- ผลรวมย่อย VAT (7%) ยอดรวมสุทธิ
- เงินมัดจำ (แยกต่างหาก ไม่รวม VAT)
- ส่วนข้อกำหนดและเงื่อนไข (กำหนดได้ใน Settings)
- ช่องลายเซ็น — ว่างจนกว่าจะเซ็น แล้วแสดงลายเซ็นดิจิทัล ชื่อผู้เซ็น และวันเวลา

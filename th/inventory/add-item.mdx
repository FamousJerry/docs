อุปกรณ์ทุกหน่วยทางกายภาพเป็นชิ้นเดียวในคลัง แม้คุณเป็นเจ้าของกล้อง 5 ตัวเหมือนกัน คุณสร้างชิ้น 5 ชิ้น แต่ละชิ้นมี Asset ID และบาร์โค้ดของตัวเอง

## เพิ่มชิ้นใหม่

<Steps>
  <Step title="เปิดโมดูลคลังอุปกรณ์">
    จากแถบเมนูด้านข้าง
  </Step>
  <Step title="คลิก 'New Item'">
    มุมขวาบนของรายการคลัง
  </Step>
  <Step title="กรอกฟิลด์ที่จำเป็น">
    ดูตารางอ้างอิงด้านล่าง
  </Step>
  <Step title="บันทึก">
    Asset ID และบาร์โค้ดถูกสร้างอัตโนมัติ ชิ้นปรากฏในรายการทันที
  </Step>
  <Step title="พิมพ์ป้าย">
    คลิก **Print Label** บนหน้ารายละเอียดของชิ้นเพื่อส่งไปยังเครื่องพิมพ์ Zebra
  </Step>
</Steps>

## ฟิลด์ที่จำเป็น

| ฟิลด์ | หมายเหตุ |
| --- | --- |
| **ชื่ออุปกรณ์** | ชื่อแสดง จะปรากฏบนใบเสนอราคา ใบแจ้งหนี้ และพอร์ทัล |
| **หมวดหมู่** | เลือกจากหมวดหมู่ที่กำหนด (กล้อง แสง ฯลฯ) |
| **อัตรา** | อัตราเช่าต่อหน่วยเวลา |
| **ประเภทอัตรา** | Daily, Weekly หรือ Monthly |
| **สภาพ** | Good, Fair หรือ Damaged (ของใหม่ส่วนใหญ่เป็น Good) |

## ฟิลด์เสริม

| ฟิลด์ | ความสำคัญ |
| --- | --- |
| **ชื่ออุปกรณ์ (ภาษาไทย)** | ชื่อภาษาไทยสำหรับลูกค้าไทย |
| **Serial Number** | Serial จากผู้ผลิต — ใช้สำหรับการเคลม |
| **ผู้ผลิต** | แบรนด์ (Sony, Aputure ฯลฯ) |
| **รุ่น** | เลข/ชื่อรุ่น |
| **วันที่ซื้อ** | เมื่อใดที่คุณซื้อ |
| **ราคาซื้อ** | ราคาที่จ่าย (ใช้ในการคำนวณค่าเปลี่ยน) |
| **ความเป็นเจ้าของ** | Owned, Sub-rented, On consignment |
| **ตำแหน่งจัดเก็บ** | ชั้นหรือชั้นกรงสำหรับการเลือก |
| **บันทึก** | สิ่งที่เฉพาะเจาะจง — quirks ที่ทราบ อุปกรณ์เสริมที่ติดมา |
| **รูปภาพ** | รูปอ้างอิงของหน่วยนี้ |

## การสร้าง Asset ID อัตโนมัติ

Asset ID ถูกสร้างอัตโนมัติจากคำนำหน้าหมวดหมู่ + เลขลำดับ:

| หมวดหมู่ | คำนำหน้า |
| --- | --- |
| กล้อง | `CAM-` |
| เลนส์ | `LEN-` |
| เสียง | `AUD-` |
| แสง | `LIT-` |
| กริป | `GRP-` |
| ไฟฟ้า | `PWR-` |

กล้องตัวแรกที่คุณเพิ่มกลายเป็น `CAM-001` ตัวที่สอง `CAM-002` เป็นต้น

## หลายหน่วยของอุปกรณ์เดียวกัน

สำหรับ Sony FX6 5 ตัวที่เหมือนกัน:

1. สร้างชิ้นในคลัง 5 ชิ้น แต่ละชิ้นชื่อ "Sony FX6"
2. แต่ละชิ้นมี Asset ID ของตัวเอง: `CAM-001` ถึง `CAM-005`
3. แต่ละชิ้นมีป้ายบาร์โค้ดของตัวเอง

เมื่อใบเสนอราคาเรียก "1× Sony FX6", JingjaiOps จองหน่วยใดก็ได้ที่ว่าง ตอน Pick & Scan ทีมสแกนหน่วยจริงที่ดึงจากชั้น — ระบบล็อก Asset ID นั้นกับงาน

นี่คือเหตุผลที่คุณสร้างหลายชิ้น ไม่ใช่ตั้ง "Quantity: 5" บนชิ้นเดียว — แต่ละหน่วยทางกายภาพต้องตามรอยได้แยก

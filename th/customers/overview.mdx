โมดูลลูกค้าเป็นแหล่งข้อมูลเดียวสำหรับทุกธุรกิจหรือบุคคลที่คุณให้เช่าอุปกรณ์ เปิดจากแถบเมนูด้านข้างเพื่อดูรายชื่อลูกค้าทั้งหมด

## หน้ารายการลูกค้า

รายการแสดงลูกค้าทั้งหมดด้วยคอลัมน์เหล่านี้:

| คอลัมน์ | สิ่งที่แสดง |
| --- | --- |
| ชื่อ | ชื่อบริษัท (หรือชื่อบุคคลหากไม่ใช่บริษัท) |
| เลขประจำตัวผู้เสียภาษี | เลข 13 หลักของไทย (ว่างหากไม่ได้กรอก) |
| ผู้ติดต่อ | ชื่อและเบอร์โทรของผู้ติดต่อหลัก |
| งานที่กำลังดำเนินการ | จำนวนงานที่ยังไม่ปิด |
| ค้างชำระ | ยอดรวมของใบแจ้งหนี้ที่ยังไม่ชำระและจ่ายบางส่วน |
| คะแนนสุขภาพ | 0–100 มีสีแยกระดับ |
| ภาษาที่ต้องการ | EN หรือ TH |

คลิกหัวคอลัมน์เพื่อเรียงลำดับ ใช้ช่องค้นหาด้านบนเพื่อกรองตามชื่อ ผู้ติดต่อ โทรศัพท์ หรือเลขประจำตัวผู้เสียภาษี

## คำสั่งด่วน

ลูกค้าแต่ละรายมีแถวคำสั่งด่วนที่ด้านบนของพาเนลรายละเอียด:

- **ใบเสนอราคาใหม่** — เปิดฟอร์มใบเสนอราคาที่กรอกลูกค้านี้แล้ว
- **งานใหม่** — ใช้ได้เฉพาะเมื่อมีใบเสนอราคาที่ accepted แล้วพร้อมแปลงเป็นงาน
- **สร้างลิงก์พอร์ทัล** — สร้าง URL พอร์ทัลใหม่และคัดลอกเข้าคลิปบอร์ด
- **อีเมล** — เปิดโปรแกรมอีเมลของคุณส่งถึงผู้ติดต่อหลัก
- **แก้ไข** — แก้ไขโปรไฟล์ลูกค้า
- **เก็บถาวร** — ซ่อนลูกค้าจากรายการเริ่มต้น เอกสารเดิมยังเชื่อมโยงอยู่

<Tip>
  ลูกค้าที่เก็บถาวรจะปรากฏหากคุณติ๊ก **แสดงที่เก็บถาวรแล้ว** ที่ด้านบนของรายการ คุณยกเลิกการเก็บถาวรได้ตลอดเวลา
</Tip>
